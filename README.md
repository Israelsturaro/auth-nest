---

## 🚀 Visão Geral

Esta aplicação oferece uma base sólida para sistemas que exigem:

- Login e registro de usuários
- Autenticação segura via **JSON Web Tokens**
- Autorização baseada em **papéis de usuário**
- Integração com **PostgreSQL**
- Arquitetura modular usando **NestJS + TypeScript**

🔐 Endpoints de Autenticação

| Método | Rota        | Descrição                                  |
|--------|-------------|--------------------------------------------|
| POST   | `/login`    | Realiza o login do usuário                 |
| POST   | `/register` | Registra um novo usuário                   |
| GET    | `/profile`  | Retorna dados do usuário autenticado (JWT) |
